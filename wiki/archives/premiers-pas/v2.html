Premiers pas

Après l’accueil, choisissez Jeu rapide, Planifier une partie, Rejoindre une partie ou Partie test, puis votre joueur. Jeu rapide crée une salle avec les réglages par défaut du serveur et ouvre le choix du héros ; Planifier ouvre les réglages existants, notamment le terrain GPS et les accès par QR code. Rejoindre demande le code de l’organisateur. Partie test ouvre la préparation sur carte fictive. Aucun de ces boutons ne démarre automatiquement une partie. La carte permet de repérer les lieux et le journal de suivre vos quêtes.

En mode GPS, le navigateur transmet vos mesures de position. En test sur carte fictive, vous déplacez le héros sur la carte. Les interactions et les actions passent dans les deux cas par les mêmes commandes du serveur.

Le serveur valide la position, les actions et leurs conséquences. Une page hébergée sur GitHub Pages permet de consulter ce guide ; une partie nécessite aussi un backend accessible.

# Menu et démarrage

Après la page de titre, le menu propose quatre choix avant la sélection du joueur :

- **Jeu rapide** : création d’une salle avec les réglages par défaut du serveur, puis affichage de la page Joueurs pour choisir le héros et se déclarer prêt. Les réglages restent accessibles.
- **Planifier une partie** : création d’une salle, puis ouverture des réglages. Les outils existants permettent de préparer le terrain GPS, les placements et les accès par QR code.
- **Rejoindre une partie** : ouverture du formulaire de code après le choix du joueur. Le serveur valide l’inscription.
- **Partie test** : préparation existante sur carte fictive.

Le retour depuis le choix du joueur ou le formulaire de connexion ramène au menu des aventures. Le retour depuis ce menu ramène à la page de titre. La reprise enregistrée reste disponible depuis l’accueil.

Ces entrées modifient uniquement le parcours de l’interface. Elles ne changent aucune règle : identité, création, inscription, configuration et démarrage restent validés par le serveur. Jeu rapide ne choisit pas automatiquement le héros et ne lance pas automatiquement la partie.
